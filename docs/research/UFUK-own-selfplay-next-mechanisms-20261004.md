# Self-play mechanism options after MC40

**Scope:** bounded research note only. The parent has the primary full-game MC/PPO two-seed run underway. This note proposes a follow-on only if that registered run misses its strength gate; it changes no source or training. There is no novelty or strength claim.

## What the terminal counterfactual test established

The predeclared 16-root × 64-common-random-continuation pilot completed both arms in 420/1,024 pairs (41.0%), but 0/16 roots cleared a positive simultaneous lower confidence bound (gate: at least 8). The radius was 1.114 at alpha=.05. Result: `NO_GO_NO_UPDATE`; all branch histories and precommitted root/action/uniform selections were preserved. No model training, SF labels, strength matches, or remote work occurred.

Separately, exact rule inspection of 134 old terminal-history prefixes (lags 1–2) found 343 one-ply terminal actions: 98 wins for the root mover, 245 draws, and zero losses; 50 of these were current e8 top-two actions (33 wins, 17 draws). There were only 3 strict two-ply same-payoff proofs in 2,705 legal actions, none in the current top two. These are action availability counts, not evidence those actions improve general play. The branch audit's 35/64 terminal rate was for one perturbed arm near old endgames, not a paired preference rate.

## Ranked fallback if MC40 fails

**1. Prioritize a test of population self-play against frozen snapshots on broad starts.** This is the most plausible whole-board alternative in this note because it changes the source of learning signal without importing labels: the learner still gets only its own terminal W/D/L, but plays against a fixed mixture of its own earlier behavior snapshots instead of only the current mirror. This tests whether symmetric self-play has hidden exploitable conventions or collapses into a narrow self-confirming style. Keep search budget, model, optimizer, total learner decisions, broad opening roots, MC target, KL/base anchor, and evaluation exactly fixed. Sample opponent identity once per game from a preregistered mixture, for example 50% current frozen behavior, 25% initial e8, and 25% one fixed pre-MC checkpoint chosen by a fixed rule before generation; randomize the learner's color. Train only on learner-side actions and orient terminal outcomes to that learner. Caps/epoch tails stay unknown. Use complete games and preserve PPO old-policy ratios; opponent identity is exogenous per episode. Count opponent inference separately, and compare at equal learner transitions *and* report actual wall/inference cost.

The experiment's control remains current-vs-current MC40 continuation; treatment changes only the opponent assignment mixture. Use the existing three-arm per-seed SF512NODES/96-games/48-paired-roots gate unchanged, both independent seeds, all existing retention/noninferiority checks, and the same held-out roots. Require treatment to pass the absolute gate in both seeds and improve paired broad-start score versus its same-seed natural-MC continuation; report scores versus each opponent stratum separately to expose opponent-pool overfit. No easier endgame starts or hyperparameter selection from the held-out games. Abort if current/opponent behavior snapshots or complete game identity cannot be restored exactly on fresh-process resume.

This has limited incremental cost (second frozen inference model, opponent selection/provenance; no search tree required), but generating on-policy learner trajectories rather than symmetric games can reduce games per wall-second. The main failure mode is learning a best response to the small snapshot pool, not a robust board policy; a frozen weak anchor can also teach bad responses. Requiring standard broad-start/SF performance and per-stratum results detects, but does not eliminate, that risk. Freeze the exact opponent snapshots and their sampling weights before generation; don't choose them by looking at the held-out strength matches.

This is established league/population self-play, not a novel algorithm. AlphaStar used a league of past/current agents and exploiters; PSRO formalizes adding responses to a population/meta-strategy. The exact small-board, low-parameter, terminal-only PPO adaptation is not a novelty claim and has no assured gain. Primary references: Vinyals et al., *Grandmaster level in StarCraft II using multi-agent reinforcement learning*, Nature 575 (2019), <https://doi.org/10.1038/s41586-019-1724-z>; Lanctot et al., *A Unified Game-Theoretic Approach to Multiagent Reinforcement Learning*, <https://arxiv.org/abs/1711.00832>.

**2. Keep terminal-root Backplay as a narrow data-mixture ablation, not the first broad-strength rescue.** If standard-start learning fails only for lack of terminal labels, draw a fixed small fraction (for example 12.5%) of starts from validated training-only full histories at preregistered 2/4/8/16/32-ply lags before observed own terminal games; keep the remaining starts on the existing broad book. Play fresh complete games with the current behavior; never reuse old W/D/L as counterfactual labels. Same learner and budget; test against the natural-root MC arm and require the existing broad SF gate plus paired noninferiority. Fullhistory matters for repetition, castling and claim-draw state. Report represented game IDs, lag, side, initial result strata, fresh terminal/cap counts and source overlap. The direct CPU evidence (35/64 branches ended within 96 plies; 23 draws, 8 Black wins, 4 White wins) suggests endgame-label enrichment, but not whole-board generalization. Overweighting these easy endgames can make a better endgame value head without helping openings/middlegames. Backplay/Reverse Curriculum Generation/HER make this established curriculum logic, not novelty: Resnick et al., <https://arxiv.org/abs/1807.06919>; Florensa et al., <https://arxiv.org/abs/1707.05300>; Andrychowicz et al., <https://arxiv.org/abs/1707.01495>.

## Deprioritized directions

- Hindsight value consistency over a completed game is the same terminal-return target already present in MC40; replaying each outcome onto more visited positions changes weighting/variance, not information. Branch counterfactuals add information only when the alternate episode actually resolves; the paired test above failed its certainty gate. Do not call the original endpoint a counterfactual label.
- Search policy improvement is a plausible later option, but much of its evidence is already diagnostic rather than absent. On project histories, the stored Gumbel-1 search distributions improved finite Stockfish expected score by +0.03785 over raw policy, yet the own-search representation training barely beat its control on held-out policy CE and failed its 0.03 adapter gate; no game strength was shown. The prior 16-simulation self-play model arena favored search over the raw policy, but that was inference-time selection, not learned strength. A full AlphaZero-style search-policy + terminal-value loop is established; use it only after a specific post-MC diagnosis and a registered same-search-budget comparison, not as a new-strength claim.
- Learned search allocation/adaptive compute is premature while value quality is unstable. Local review of the recent efficient-self-play paper reports improved deep-target fidelity but online training behind by roughly 60–100 ladder Elo; this warns that better targets or fewer calls need not improve strength. Profile critical-path throughput and calibrate value before introducing an allocator.

References for standard self-play/search: Silver et al., AlphaZero, <https://arxiv.org/abs/1712.01815>; Wu, *Accelerating Self-Play Learning in Go* (KataGo), <https://arxiv.org/abs/1902.10565>. This note reports no new empirical strength result.
