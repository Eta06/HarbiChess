# DEVRIYE stratified continuation replay preregistration

## Why this follow-up exists

The frozen `devriye-continuous-pilot-20260830-06` run stopped before learning: only
2/12 standard-start games reached a known terminal outcome, while 10/12 hit the
96-ply cutoff. The preregistered four-game terminal floor is not relaxed and
max-ply samples remain unknown rather than being mislabeled as draws.

## Frozen change

- Keep the network, Full Gumbel allocator, 64 simulations, 12 games per update,
  96-ply per-game limit, policy target production, learner exposure, batch mix,
  validation checkpoints, and every downstream gate unchanged.
- Start the 12 fresh latest-network games from 12 deterministic, non-overlapping
  historical states: four opening, four middlegame, and four endgame states.
- Historical records provide only legal starting states. Every move, search
  target, terminal result, and replay row after that state is newly generated by
  the current latest network.
- Select starts before observing new outcomes. Within each phase, order distinct
  games and states by a deterministic hash of seed and replay identity.
- Preserve each starting state's complete root/history state so repetition,
  fifty-move, castling, and en-passant rules remain exact.
- Keep only real terminal outcomes for WDL learning. A continuation that reaches
  its own 96-ply budget is still masked from value loss.
- Keep the existing requirement of at least four known-outcome games per update.
  Do not change the phase quota, terminal floor, sample count, or compute after
  seeing results.

## Decision

The same three-update continuous-chain gates remain authoritative. Failure to
produce four terminal games stops before learning. Passing terminal yield only
authorizes the already-preregistered learner and qualification sequence; it is
not itself evidence for generation or promotion.
