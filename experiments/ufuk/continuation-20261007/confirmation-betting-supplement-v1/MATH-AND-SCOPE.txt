For a single metric observe FIXED n=48 independent root blocks X_i in [L,U].
Null: average of their population expectations m_i is <=mu, where mu>L.
For each FIXED fraction f in {.1,.2,...,1} define lambda=f/(mu-L) and
K_f(mu)=product_i (1+lambda*(X_i-mu)). Every factor is nonnegative.
Independence gives E K_f =product_i[1+lambda*(m_i-mu)]. AM-GM bounds this
by [1+lambda*(average m_i-mu)]^n <=1. Mixture E_mu=average_f K_f therefore
is a nonnegative e-value. Markov yields P(E_mu>=1280)<=1/1280=.00078125.
This works with unequal root expectations; independence is essential.

Each factor=(1-f)+f*(X_i-L)/(mu-L) is decreasing in mu. Hence E_mu is
monotone decreasing. At the sample mean, observed AM-GM gives E<=1. Invert
below that mean. The reported LCB is a rejected-side endpoint: if LCB>the
true average mean, monotonicity implies E_at_true_mean>=1280. Thus one-sided
coverage is >=1-1/1280. At true mean=L, boundedness forces every X_i=L
almost surely; code returns L. f=1 and X_i=L contributes zero capital, not
NaN. Sum logs is stable, and the final reported endpoint is CERTIFIED with
exact rational arithmetic using exact represented outcomes, exact fractions
1/10..1, and EXACT rejection threshold1280. Float bisection cannot inflate
the certified endpoint; uncertifiable numeric failure returns L conservatively.
